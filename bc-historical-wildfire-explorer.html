Project Overview

BC Historical Wildfire Explorer is a full-stack web GIS application for exploring 23,306 historical wildfire records across British Columbia from 1917 to 2022. The interface provides a complete point-based historical overview and year-specific wildfire perimeter maps, with filtering by year, cause, fire size, BC Wildfire Service fire centre, and fire zone.

The application uses PostgreSQL/PostGIS as its spatial database rather than relying on a static dataset in the browser. Raw source data is preserved separately, while cleaned application tables store validated geometry, indexes, and precomputed wildfire-to-fire-zone relationships. A Node.js/Express API handles filtering and sends GeoJSON and summary statistics to the React/Leaflet interface. The production database is hosted on Neon, while Render hosts the API and frontend.

Features

01

Historical Overview

Explore the complete historical record using representative points derived from mapped wildfire polygons.

02

Annual Fire Perimeters

Switch to actual mapped wildfire perimeters for a selected year.

03

Multi-Criteria Filtering

Filter by year, cause, minimum and maximum fire size, fire centre, and fire zone.

04

Fire Management Geography

Explore wildfire records in relation to BC Wildfire Service fire centres and fire zones.

05

Interactive Summaries & Popups

View filtered fire counts, area burned, and individual wildfire attributes directly from the map.
